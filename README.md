# Точка

Минималистичный QR-сканер для GitHub Pages. Камера и изображения обрабатываются на устройстве. История сканирований не сохраняется. В localStorage сохраняются тема и ручной выбор камеры.

## Публикация

GitHub Actions устанавливает закреплённую версию ZXing-WASM 2.2.1, копирует JS/WASM и лицензии в `dist/vendor`, запускает браузерные тесты и публикует `dist`. В Settings → Pages источник публикации должен быть GitHub Actions. Пользовательский домен задаётся существующим `CNAME`; HTTPS обязателен для камеры.

На опубликованном сайте нет загрузки библиотеки с CDN. Установка зависимостей нужна только при сборке. Готовая папка `dist` является статическим сайтом и доступна как артефакт `tochka-qr-site` в успешном запуске Actions.

## Локальная проверка

```sh
npm install --ignore-scripts
npm run build
npx playwright install
npm test
python3 -m http.server 8000 --directory dist
```

## Камера

Квадратный центральный участок видео совпадает с видимой областью. Основной задний объектив выбирается по доступным браузеру названиям устройств. Универсально определить физический объектив 1x через браузер нельзя. При необходимости выберите камеру вручную. Фокус и фонарик используются только при наличии соответствующих возможностей.

## Распознавание

ZXing-C++ через WebAssembly работает в отдельном Worker. Быстрые проходы чередуются с поиском в большем разрешении, усиленным поиском, контрастом и умеренным повышением резкости. Эти меры не восстанавливают полностью засвеченные или потерянные детали. Одновременно распознаётся один QR-код.

Тесты Chromium, Firefox и WebKit проверяют загрузку локального WASM, текстовые и URL-результаты, искусственные примеры с логотипом, слабым бликом и лёгким размытием, тему, узкий экран и ошибки. Камера дополнительно проверяется на синтетическом видеопотоке Chromium. Это не заменяет проверку настоящего автофокуса, выбора объектива и скорости на телефоне.

Старые `jsQR.js` и `LICENSE-jsQR.txt` оставлены для истории перехода и не включаются в публикацию новой версии.
