# Точка 3.0

Чёрно-белый QR-сканер с двумя темами, камерой и загрузкой изображения. Статический сайт на GitHub Pages. Камера и изображения обрабатываются на устройстве, история результатов не сохраняется. localStorage хранит только тему и ручной выбор камеры.

## Архитектура

- `index.html`, `styles.css`: адаптивный монохромный интерфейс.
- `app.js`: пользовательские состояния, результат, изображение, планирование кадров.
- `camera.js`: разрешения, выбор устройства, фокус, фонарик и освобождение видеопотока.
- `decoder-client.js`: один запрос распознавания за раз, передача буферов и отмена Worker.
- `qr-worker.js`: ZXing-WASM 2.2.1, встроенный BarcodeDetector при поддержке QR и резервный jsQR.
- `scripts/build.cjs`: статический пакет `dist` с локальными библиотеками и лицензиями.

Усиленный поиск ZXing включён с первого кадра. Встроенный распознаватель получает раннюю попытку на чередующихся кадрах; ошибки или превышение тайм-аута отключают его до пересоздания Worker. После неудачи выбирается дополнительная стратегия, а не все фильтры подряд. На медленных проходах число дополнительных попыток ограничивается. Размер обычных кадров и пауза адаптируются к времени обработки; периодические кадры большего разрешения сохраняют шанс прочитать мелкие детали. Очереди старых кадров нет.

Фото проходят дополнительные варианты разрешения, контраста и умеренного повышения резкости. Одновременно читается один QR. Эти меры не восстанавливают уничтоженные бликом или сильным смазыванием детали.

## Камера и ограничения

Видимая квадратная область совпадает с распознаваемым центральным участком кадра. Основная задняя камера выбирается по доступным браузеру названиям. Универсального способа гарантировать физический объектив 1x нет: при необходимости выберите камеру вручную. Настройка zoom=1 означает базовое увеличение выбранного видеотрека, а не идентификацию объектива.

Фонарик и непрерывный автофокус доступны только при поддержке браузером и камерой. После результата, отмены, ухода со страницы или скрытия вкладки камера останавливается. Автоматического повторного включения нет.

Целевой проблемный сценарий: LG V30+ с Chrome, медленное чтение QR с логотипом. Реальный образец не предоставлен. Скорость на этом телефоне и устранение конкретной проблемы не подтверждены. Синтетические тесты не заменяют реальные измерения.

## Публикация

GitHub Actions собирает сайт, запускает браузерные тесты и публикует `dist` только после успешных проверок в `main`. В Pages выбран GitHub Actions. `CNAME` сохраняет существующий домен, HTTPS включён.

Библиотеки при сканировании загружаются с того же сайта. Во время сборки нужны npm и загрузка текстов лицензий. В успешном запуске Actions есть архив готового сайта `tochka-qr-site` и браузерный отчёт.

```sh
npm install --ignore-scripts
npm run build
npx playwright install
npm test
python3 -m http.server 8000 --directory dist
```

## Проверки

Chromium, Firefox и WebKit: синтетические QR с прямоугольным/круглым значком, бликом, размытием, низким контрастом и поворотом; резервные декодеры; ошибки; обе темы; узкие экраны; безопасное отображение результата. Искусственный видеопоток Chromium проверяет кадрирование, отмену разрешения и выключение треков. Проверки жизненного цикла покрывают повторные запуски и скрытие вкладки. Скриншоты разных размеров и тем сохраняются в отчёте, но их наличие само по себе не означает ручную визуальную проверку.

Перед оценкой скорости сравните один и тот же QR с одинакового расстояния и при одинаковом освещении. Если камера долго фокусируется, отодвиньте телефон; для кода на экране используйте скриншот.

## Безопасность

Результат выводится как текст. Автоматических переходов и запуска команд нет. Кнопка открытия появляется только для HTTP/HTTPS без встроенных учётных данных. Проверяйте адрес самостоятельно. Регистрации, аналитики и отправки изображений нет.
